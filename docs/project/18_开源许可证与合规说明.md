# 18. 开源许可证与合规说明

> 本文不是法律意见，只是工程合规提醒。当前项目决策为：**源码全部公开，因此 AGPL 网络交互义务按默认开源治理处理，风险显著降低。**

## 1. 合规总原则

1. CherryGraph Studio 自研代码公开。
2. Cherry Studio Fork 修改公开。
3. Docmost Fork 修改公开。
4. 保留 Cherry Studio、Docmost、Graphify 原始 LICENSE、版权声明和修改历史。
5. Web UI 提供源码获取入口、许可证页面、第三方组件列表和无担保声明。
6. 构建和镜像交付时保留 license bundle 与 SBOM。

## 2. Cherry Studio

Cherry Studio 社区版采用 AGPL-3.0。本项目选择 Fork 并重构 Web 版，因此要求：

| 要求 | 处理方式 |
|---|---|
| 保留 LICENSE | 仓库保留原始 LICENSE 文件和版权声明。 |
| 修改版源码提供 | 项目源码全部公开，Web UI 提供源码入口。 |
| 网络交互场景 | 用户通过 Web 使用时可访问对应源码。 |
| 修改可追踪 | Git 历史记录修改方、修改时间和变更内容。 |

## 3. Docmost

Docmost core 使用 AGPL-3.0。本项目决策为 Fork 开源版 + 自建 Bridge，不购买 Enterprise。

要求：

1. `external/docmost/` 保留 Docmost 原始 LICENSE。
2. Fork 分支公开。
3. Bridge 新增路由和 webhook 代码公开。
4. 不使用 Enterprise API/MCP 相关闭源能力。
5. 每次 upstream rebase 记录基线 commit 和冲突处理。

## 4. Graphify

Graphify 使用 MIT license。集成要求：

1. 保留 Graphify LICENSE。
2. 保留 Graphify 版权声明。
3. 记录 Graphify pin 版本或 commit。
4. 后台调用 CLI/库时保留依赖许可证清单。

## 5. 第三方依赖与 SBOM

必须维护：

1. 前端依赖许可证清单。
2. 后端依赖许可证清单。
3. Python Worker 依赖许可证清单。
4. Docker 镜像 SBOM。
5. 源码中的第三方代码声明。
6. 字体、图标、图片等静态资源许可证。

## 6. Web UI 合规页面

平台 UI 应包含：

1. 关于页面。
2. 开源许可证页面。
3. 源码获取入口。
4. 第三方组件列表。
5. 无担保声明。
6. 当前部署版本与 commit hash。

## 7. 发布前合规 Checklist

- [ ] Cherry Studio AGPL LICENSE 已保留。
- [ ] Cherry Studio Fork 修改源码已公开。
- [ ] Docmost AGPL LICENSE 已保留。
- [ ] Docmost Fork 修改源码已公开。
- [ ] Graphify MIT license 已保留。
- [ ] 第三方依赖 SBOM 已生成。
- [ ] Web UI 已提供许可证和源码入口。
- [ ] 镜像包含 license bundle。
- [ ] 管理员文档包含许可证说明。

## 8. 删除的旧口径

本版本不再使用以下旧表述：

- “协商商业许可”。
- “避免 AGPL 义务”。
- “Docmost 企业版 API/MCP 作为主集成路线”。
- “商业使用边界待确认”。

原因：项目决策已经变更为内部小团队使用、源码全部公开、Docmost Fork 开源版 + 自建 Bridge。
