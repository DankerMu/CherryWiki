# 16. 实施路线图与里程碑

## 1. 总体阶段

```text
Phase 0 许可与技术预研
Phase 1 Cherry Web 基础平台
Phase 2 Graphify Wiki 与上传归档
Phase 3 Docmost Shell 双向同步
Phase 4 GraphRAG 聊天闭环
Phase 5 权限、安全、审计、运维增强
Phase 6 知识治理和高级 Agent
```

## 2. Phase 0：许可与技术预研

目标：消除不可逆风险。

交付：

1. Cherry Studio Fork 可行性评估。
2. AGPL 合规方案。
3. Docmost Enterprise API/Fork 路线确认。
4. Graphify CLI 在容器中运行 PoC。
5. Graphify 输出 schema 样例分析。
6. Wiki 页面格式规范初版。

退出条件：

- 法务接受 AGPL 策略。
- Graphify 能在后台跑出 wiki 和 graph.json。
- Docmost 页面可导入导出 Markdown。

## 3. Phase 1：Cherry Web 基础平台

交付：

1. Docker Compose 基础环境。
2. Web 登录、用户、Group、Space。
3. 模型管理。
4. 基础聊天流式输出。
5. 会话历史。
6. 管理后台初版。

退出条件：

- 多用户可登录。
- 用户权限能限制 Space 可见性。
- Chat 可调用模型。

## 4. Phase 2：Graphify Wiki 与上传归档

交付：

1. Upload API。
2. Source Archive。
3. Ingestion Worker。
4. Canonical Wiki Repo。
5. Graphify Worker。
6. Graphify Run 管理后台。
7. Graphify 输出解析。

退出条件：

- 上传资料后能自动跑 Graphify。
- 生成 Wiki 页面、graph.json、report。
- 页面写入 Canonical Wiki Repo。

## 5. Phase 3：Docmost Shell 双向同步

交付：

1. Docmost 部署。
2. Space 映射。
3. Graphify → Docmost 导入。
4. Docmost → Repo 回写。
5. 页面状态和同步状态。
6. 权限映射。

退出条件：

- Graphify 页面可在 Docmost 浏览。
- Docmost 编辑能同步回 Repo。
- 权限映射通过测试。

## 6. Phase 4：GraphRAG 聊天闭环

交付：

1. Wiki chunking。
2. Embedding 索引。
3. BM25/全文索引。
4. graph_nodes/edges 导入。
5. 混合检索。
6. 引用和图谱路径展示。
7. GraphRAG Prompt。

退出条件：

- Chat 能基于 Published Wiki 回答。
- 回答有引用和图谱解释。
- 无权限内容不会泄露。

## 7. Phase 5：权限、安全、审计、运维增强

交付：

1. 审计日志。
2. 上传安全增强。
3. Graphify 任务失败回滚。
4. 权限一致性检查。
5. 备份恢复脚本。
6. 监控面板。

退出条件：

- 通过安全验收。
- 通过恢复演练。
- Worker 异常不影响已发布知识。

## 8. Phase 6：知识治理和高级 Agent

交付：

1. 候选更新审核。
2. 低置信关系审核。
3. 重复页面合并建议。
4. 知识冲突检测。
5. Agent 工具链。
6. MCP Gateway。

退出条件：

- 编辑者可以处理 Graphify proposals。
- Agent 可调用图谱和 Wiki 工具。

## 9. 推荐团队分工

| 小组 | 职责 |
|---|---|
| Web 前端 | Cherry Web、Admin、Chat UI、引用和图谱展示。 |
| 后端平台 | API、Auth、RBAC、任务、审计。 |
| 知识工程 | Graphify Worker、Wiki Core、GraphRAG。 |
| Wiki 集成 | Docmost Bridge、同步、权限映射。 |
| DevOps | Docker、监控、备份、CI/CD。 |
| QA | 自动化测试、权限测试、安全测试。 |

## 10. 里程碑验收表

| 里程碑 | 必须演示 |
|---|---|
| M1 | 多用户 Web Chat。 |
| M2 | 上传资料自动 Graphify。 |
| M3 | Graphify Wiki 在 Docmost 可编辑。 |
| M4 | 人工编辑后 Chat 使用新知识。 |
| M5 | GraphRAG 带引用和图谱路径。 |
| M6 | 权限、安全、审计闭环。 |
