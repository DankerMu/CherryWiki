# 19. 资料依据与外部来源

本文档包基于 2026-04-27 查询到的公开资料和你的项目决策整理。关键外部依据如下。

## 1. Cherry Studio

- Cherry Studio GitHub README 说明社区版是支持 Windows、macOS、Linux 的桌面客户端，并支持多 LLM Provider、本地模型、文档/数据处理、MCP 等能力。  
  URL: https://raw.githubusercontent.com/CherryHQ/cherry-studio/main/README.md

- Cherry Studio README 中的 Enterprise Edition 描述了统一模型管理、企业知识库、细粒度访问控制、私有化部署、后端服务等能力方向。  
  URL: https://raw.githubusercontent.com/CherryHQ/cherry-studio/main/README.md

- Cherry Studio LICENSE 是 GNU Affero General Public License Version 3。  
  URL: https://raw.githubusercontent.com/CherryHQ/cherry-studio/main/LICENSE

- Cherry Studio 文档显示 MCP Server 可在设置中添加，类型包括 STDIO，并可在聊天中启用。  
  URL: https://docs.cherry-ai.com/docs/en-us/advanced-basic/mcp/config

- Cherry Studio 知识库文档显示其知识库支持文件、文件夹、网站链接、sitemap、纯文本笔记，并会对文档切片和向量化，问答时检索相关片段。  
  URL: https://github.com/CherryHQ/cherry-studio-docs/blob/main/i18n/english/knowledge-base/knowledge-base.md

## 2. Graphify

- Graphify GitHub README 显示其可把代码、文档、论文、图片、音视频等转成知识图谱，并输出 `graph.html`、`GRAPH_REPORT.md`、`graph.json`、`cache/`。  
  URL: https://github.com/safishamsi/graphify

- Graphify README 显示其支持 `--wiki` 生成 agent-crawlable wiki，支持 `query`、`path`、`explain`、`--update`、`--watch`、`--neo4j`、`--mcp` 等命令。  
  URL: https://github.com/safishamsi/graphify

- Graphify README 显示 `graph.json` 不应整体塞入 prompt，而应先读 `GRAPH_REPORT.md`，再用 `graphify query` 取小子图；Graphify 可通过 `python -m graphify.serve graphify-out/graph.json` 暴露 MCP，提供 `query_graph`、`get_node`、`get_neighbors`、`shortest_path`。  
  URL: https://github.com/safishamsi/graphify

- Graphify GitHub 页面显示 License 为 MIT。  
  URL: https://github.com/safishamsi/graphify

## 3. Docmost

- Docmost 官网说明其是 on-premises wiki，支持实时协作、RBAC、Team Spaces、页面验证、AI、MCP、附件搜索、企业 SSO 等能力。  
  URL: https://docmost.com/

- Docmost GitHub README 说明其是开源协作 Wiki，功能包括实时协作、Diagrams、Spaces、权限管理、Groups、评论、页面历史、搜索、文件附件等；Docmost core 使用 AGPL-3.0，Enterprise 功能采用企业许可。  
  URL: https://github.com/docmost/docmost

- Docmost 安装文档说明 Docker 是推荐安装方式，示例 docker-compose 包含 `docmost/docmost`、PostgreSQL、Redis，并提供 `/api/health` 健康检查。  
  URL: https://docmost.com/docs/installation/

- Docmost Import & Export 文档说明可导入 Markdown、HTML、DOCX、Notion ZIP、Confluence export，并可导出单页或 Space 为 Markdown/HTML/ZIP。  
  URL: https://docmost.com/docs/user-guide/import-export

- Docmost API 文档说明 REST API 是企业功能，需要有效企业许可。  
  URL: https://docmost.com/docs/user-guide/api/

- Docmost MCP 文档说明 MCP 是企业功能，需要有效企业许可，并提供页面搜索、读取、创建、更新、Space 管理等工具。  
  URL: https://docmost.com/docs/user-guide/mcp

- Docmost Groups 文档说明 Groups 可用于集体管理权限，并可将 Group 授权给 Space，权限包括 Full Access、Can Edit、Can View。  
  URL: https://docmost.com/docs/user-guide/groups/
